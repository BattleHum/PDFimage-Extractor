# MIL-EXTRACT

**Інструмент для автоматизованого вилучення зображень із PDF-документів.**

MIL-EXTRACT — настільний застосунок із графічним інтерфейсом, призначений для пошуку, вилучення та збереження зображень із PDF-файлів із формуванням CSV-звіту.

Програма використовує PyMuPDF для аналізу сторінок PDF та PyQt5 для графічного інтерфейсу.

---

## Можливості

- **Повне сканування PDF:** послідовна обробка всіх сторінок документа.
- **Вилучення зображень:** пошук зображень через `page.get_text("dict")`.
- **Додаткова перевірка:** використання `page.get_image_info()` для виявлення пропущених зображень.
- **Fallback-механізм:** рендеринг області зображення у PNG, якщо отримати оригінальні байти не вдалося.
- **Збереження результатів:** автоматичне створення окремих файлів зображень.
- **CSV-звіт:** формування таблиці з інформацією про кожне вилучене зображення.
- **Перегляд звіту:** вбудоване вікно для пошуку, сортування та перегляду CSV.
- **Мініатюри:** попередній перегляд вилучених зображень безпосередньо в програмі.
- **Журнал роботи:** відображення перебігу обробки та повідомлень про помилки.
- **Фонове виконання:** обробка PDF виконується в окремому потоці GUI.

Основні елементи програми:

8. Вбудований переглядач CSV-звіту.

## Принцип роботи

MIL-EXTRACT використовує два механізми пошуку зображень.

### 1. Основний механізм

Для кожної сторінки PDF виконується:

```python
page.get_text("dict")
```

Після цього відбираються блоки з типом `1`, які відповідають зображенням.

Програма намагається отримати байти зображення та зберегти їх у файл.

### 2. Додаткова перевірка

Після основного етапу виконується:

```python
page.get_image_info(hashes=True, xrefs=True)
```

Це дозволяє додатково перевірити зображення, присутні на сторінці.

Якщо виявлено область, якої немає серед збережених блоків, програма використовує резервний механізм — рендеринг відповідної області сторінки у PNG.

### Важливо

Поточна реалізація:
- не фільтрує сторінки;
- не відбирає зображення за розміром;
- не класифікує зображення за вмістом;
- не виконує дедуплікацію;
- зберігає кожне знайдене входження зображення.

Результати залежать від структури та особливостей конкретного PDF-документа.

## CSV-звіт

Після завершення обробки програма створює файл:

```text
extraction_report.csv
```

Звіт містить такі поля:

| Поле | Опис |
|---|---|
| `page` | Номер сторінки PDF |
| `image_number` | Порядковий номер зображення на сторінці |
| `filename` | Назва збереженого файлу |
| `method` | Метод вилучення |
| `xref` | Ідентифікатор XREF |
| `source_width` | Ширина вихідного зображення |
| `source_height` | Висота вихідного зображення |
| `bbox` | Координати області зображення |

CSV можна переглядати у вбудованому вікні програми або відкривати зовнішнім табличним редактором.

## Встановлення та запуск із вихідного коду

### Вимоги

- Python 3.12
- Windows 11 x64
- Git (для клонування репозиторію)

### 1. Клонування репозиторію

```bash
git clone https://github.com/USERNAME/MIL-EXTRACT.git
cd MIL-EXTRACT
```

Заміни `USERNAME` на ім'я свого GitHub-акаунта.

### 2. Створення віртуального середовища



```bash
python -m pip install --upgrade pip

```

```bash
python main.py
```

## Створення EXE

У репозиторії передбачено BAT-файл для автоматизованої збірки через PyInstaller.

Переконайся, що:
- створено `.venv312`;
- присутній `assets/MIL-EXTRACT.ico`;
- файл `main.py` знаходиться в корені проєкту.

Запусти:

```powershell
.\build_exe.bat
```

Після успішної збірки виконуваний файл буде розташований тут:

```text
dist/MIL-EXTRACT.exe
```

EXE містить інтерпретатор Python та необхідні залежності, тому окреме встановлення Python на комп'ютері користувача не потрібне.

**Примітка:** збірку необхідно створювати окремо для кожної цільової операційної системи. Поточна версія орієнтована на Windows 11 x64.
